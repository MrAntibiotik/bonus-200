# Інструкції для Claude Code

Проєкт: статичний навчальний сайт (один файл `index.html`), публікується на GitHub Pages з репозиторію `mr_shedy`.
Власник: GitHub-акаунт **MrAntibiotik**. Мова інтерфейсу й комітів — українська.

## Правила роботи з файлом
- Не розбивай `index.html` на кілька файлів і не додавай збірку (npm, bundlers) без прохання.
- Контент уроків, карток, тесту і чек-листа — у масивах `LESSONS`, `CARDS`, `QUIZ`, `CHECKS` всередині `<script>`.
- Ключі localStorage: `p205_done`, `p205_boxes`, `p205_best`, `p205_ck`. Не перейменовуй — зітреться прогрес користувача.
- Юридичні формулювання не змінюй без перевірки за чинною редакцією на zakon.rada.gov.ua.
- Після змін: перевір синтаксис JS, закоміть з українським повідомленням, `git push`.
