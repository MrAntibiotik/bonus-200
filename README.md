# bonus-200

Пранк-сторінка «ШедіБанк — подарунок 200 ₴» для GitHub Pages.

## Як працює
1. Фейковий (вигаданий) банк обіцяє 100–200 ₴ за реєстрацію.
2. «Реєстрація» нічого нікуди не відправляє — просто запускає сюрприз.
3. Фулскрін, гачі-ролик від початку до кінця зі звуком на повну.
4. Кнопки «Закрити / Вимкнути звук» не працюють: стрибають, перевертаються, крутяться і множаться. Пранк закінчується разом з відео.

## Відео
Поклади свій ролик у `media/prank.mp4`. Якщо файлу немає — замість відео буде заглушка з синтезованою сиреною.

Налаштування (підсилення звуку, максимум кнопок, тривалість етапів) — на початку `prank.js`.

## Пасхалка 🥚
- клікнути крапку в футері після «© 2026 ШедіБанк»
- або 5 разів клікнути по лого
- або набрати на клавіатурі `shedy`

## Публікація
Settings → Pages → Deploy from a branch → гілка з цими файлами, папка `/ (root)`.

## Звуки
- `media/moan.mp3` — стогін, грає на екрані «Завантаження приватного контенту». Нема файлу — буде тиша.
- `media/prank.mp4` — гачі-ролик у фіналі.

Порядок: банк → реєстрація → 18+ → «приватний контент» (стогін) → «ВАС СПАЛИЛИ» (сирена) → «жартую» → гачі (весь ролик зі звуком) → «Тебе розіграли».
