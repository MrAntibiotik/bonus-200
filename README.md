# Постанови КМУ № 205 і № 1009 — навчальний курс

Інтерактивний курс для фахівця з розробки ПЗ у державній установі.

Відкрити: https://mrantibiotik.github.io/mr_shedy/ (після ввімкнення GitHub Pages)

## Що всередині
- **Уроки (16)** — Обов'язкові вимоги № 205, Порядок локалізації, зміни № 382, 893, 1579, 373, безперервність за № 1009, суміжні акти, практика.
- **Картки (52)** — повторення за системою Лейтнера.
- **Тест** — 15 випадкових запитань із банку на 30, з поясненнями.
- **Чек-лист (28 пунктів)** — перевірка відповідності конкретної системи.

Прогрес зберігається в localStorage браузера.

## Джерела і застереження
- Текст № 205 — редакція з урахуванням змін до № 373 від 25.03.2026.
- Положення № 1009 — за аналітичними розборами (mind.ua, GigaCloud, Мінцифри).
- Перед використанням у робочих документах звіряти з чинною редакцією на https://zakon.rada.gov.ua (205-2025-п, 1009-2026-п).

Матеріал навчальний, не є офіційним тлумаченням.

## Технічно
Один файл `index.html` без збірки й залежностей (лише Google Fonts). GitHub Pages: Settings → Pages → Deploy from a branch → потрібна гілка, папка `/ (root)`.
